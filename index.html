Google2Snipe-IT

tool

Syncs ChromeOS device data from the Google Admin SDK into Snipe-IT asset inventory. Authenticates with a service account using domain-wide delegation, paginates the full device list, creates models and categories automatically, and handles API rate limiting with exponential backoff. Runs on a systemd timer.

Python Google Admin SDK Snipe-IT
Source

Merakitosnipeit

tool

Pulls the device inventory from a Cisco Meraki organisation into Snipe-IT. Caches categories and models at startup to keep API calls down, deduplicates by serial or asset tag so runs are idempotent, and ships with APScheduler, systemd timer, and Docker deployment paths.

Python Meraki API Docker
Source

toner-tracker-snipeit

app

A small toner stock and replacement tracker for schools, built on FastAPI and SQLite. Pulls printer and asset data from Snipe-IT, raises low-stock alerts, and puts the whole thing behind a simple web dashboard.

Python FastAPI SQLite
Source

SnipeITAgent

agent

A lightweight cross-platform agent that collects hostname, serial, model and assigned user from a device and pushes it to Snipe-IT over the API. Runs silently in the background and compiles to a standalone executable for macOS, Windows and Linux.

Python cross-platform Snipe-IT
Source

~/about

A bit more context

I started out writing small tools to automate things I found tedious, which is still more or less what I do — the tools just got sharper and the problems got more interesting.

Most of my time goes to Python — tooling, automation and network programming — and to security work: reverse engineering, exploit development, and the unglamorous business of making infrastructure harder to walk into. I like the overlap. Understanding how something is built is the fastest route to understanding how it breaks, and vice versa.

Outside of that I play CTFs, maintain a homelab that is far more complicated than it needs to be, and write up whatever I learn so the next person doesn't have to rediscover it. If you're working on something in this space, I'd like to hear about it.
